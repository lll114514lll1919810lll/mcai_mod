## What's New in v1.6.1 (Hotfix)

### Critical Bug Fixes
- **Fixed approval command execution context**: Approved commands now execute with the original requester's position, dimension, and rotation instead of the admin's context. Previously, when player A requested a command and admin B approved it, the command would run at B's location (e.g., `/tp @s ~ ~ ~` would teleport to the admin, not the requester).
- **Fixed concurrent player counter leak**: When the AI thread pool is full and rejects a task, the non-admin concurrent counter and cooldown are now properly rolled back. Previously, a rejected task would permanently increment the counter, eventually blocking all non-admin players from using AI with a "concurrent limit" message.
- **Fixed ToolDispatcher not refreshing after `/aireload`**: The `ToolDispatcher` is now rebuilt alongside `SearchRouter` during config reload. Previously, the old dispatcher kept a reference to the closed search router, causing `/aikb` and tool calls to fail after `/aireload`.
- **Fixed review severity grading inversion**: AI-returned severity scores are now correctly mapped to three tiers (-10/-20/-30). Previously, the most severe violations (-30) were incorrectly downgraded to the mildest tier (-10), making the review system effectively useless.

### Improvements
- **Configurable red card threshold**: The cumulative penalty threshold for red cards now reads from `redCardThreshold` in config instead of a hardcoded -60.
- **Thread-safe chat log clearing**: Chat log clearing during behavior review is now synchronized to prevent race conditions with concurrent AI query threads.
- **Graceful thread pool rejection handling**: `RejectedExecutionException` is now caught and reported to the player with the concurrent-limit message, instead of silently failing.

### Compatibility
- Built for Minecraft 26.1.2 (supports 26.1 ~ 26.2)
- Fabric Loader 0.19.2, Fabric API 0.149.1+26.1.2
- ModMenu 20.0.0-alpha.1+
- Java 25 required

## Installation
1. Download `mcai-26.1.2-1.6.1.jar` to `mods/` folder
2. (Optional) Download `mcai-lang-pack.zip` for clients without mod
3. Restart server or run `/aireload`

## Server Resource Pack Configuration
Add to `server.properties`:
```
resource-pack=https://github.com/lll114514lll1919810lll/mcai_mod/releases/download/v1.6.0/mcai-lang-pack.zip
resource-pack-sha1=3d5022ba65a31ee19fbbe265bd28c1097e35e95e
resource-pack-prompt=MCAI language pack for AI message translations
resource-pack-required=false
```
