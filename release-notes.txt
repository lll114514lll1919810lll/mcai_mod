## What's New in v1.6.0

### Bug Fixes
- Fixed tool call limit messages being incorrectly output as AI responses (now properly handled as errors via `mcai.chat.error`)
- Fixed fallback API calls missing `Authorization` header, which caused 401 errors
- Fixed i18n color codes not being re-applied after `%s`/`%d` placeholders in approval messages
- Fixed premature "invalid ID" error when approving command chains

### Internationalization
- Replaced hardcoded visible text with `Component.translatable` across `ReviewEngine.java`, `CommandRegistry.java`, and other files
- All user-facing strings now use proper i18n keys (e.g., `mcai.review.status.empty`, `mcai.cmd.suggest.chain`)

### New Features
- **Cancel hints**: When AI requests approval, the requester now receives a clickable hint with `/aicancel [ID]` to cancel pending commands/chains
- **Version awareness**: System prompts now include information about the 26.x version naming convention to prevent AI from misidentifying the game version
- **Console review support**: Console can now trigger behavior reviews
- **Prompt management**: Added `/airesetprompts` command (admin-only) to reset system and review prompt files

### Improvements
- Optimized system and review prompts for more efficient AI operation
- Search results increased from 5 to 7 for `/aikb` command
- Command normalization for more reliable execution after `/aireload`

### Compatibility
- Built for Minecraft 26.1.2 (supports 26.1 ~ 26.2)
- Fabric Loader 0.19.2, Fabric API 0.149.1+26.1.2
- ModMenu 20.0.0-alpha.1+
- Java 25 required

## Installation
1. Download `mcai-26.1.2-1.6.0.jar` to `mods/` folder
2. (Optional) Download `mcai-lang-pack.zip` for clients without mod
3. Restart server or run `/aireload`

## Server Resource Pack Configuration
Add to `server.properties`:
```
resource-pack=https://github.com/lll114514lll1919810lll/mcai_mod/releases/download/v1.6.0/mcai-lang-pack.zip
resource-pack-sha1=3d5022ba65a31ee19fbbe265bd28c1097e35e95e
resource-pack-prompt=MCAI language pack for AI message translations
resource-pack-required=false
```
